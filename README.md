# Python Programming Internship Projects

This repository contains three Python programming projects developed as part of my Python Programming Internship.

## 1. Hangman Game

A simple word guessing game developed using Python.

### Features
- Random word selection
- Player name input
- Letter guessing
- 6 chances for wrong guesses
- Repeated letter checking
- Win and Game Over conditions

### File
`hangman.py`

---

## 2. Stock Portfolio Tracker

A Python program that calculates the total investment value based on the selected stock and quantity.

### Features
- Displays available stocks
- Predefined stock prices
- Stock name input
- Quantity input
- Calculates total investment value
- Handles invalid stock names

### File
`stock_portfolio.py`

---

## 3. Basic Chatbot

A simple rule-based chatbot developed using Python that can have a basic conversation with the user.

### Features
- User name input
- Greetings
- Basic conversation
- Simple questions and responses
- Python-related response
- Exit command

### File
`chatbot.py`
